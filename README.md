# Beckley Health site

Company site for Beckley Health (Beckley Retreats, P.B.C.).

- `index.html`, `research.html`, `mission.html` and `speaking.html` are the pages. `ecosystem.html` only redirects to the mission page. Styles are in `assets/site.css`. No scripts, no tracking, no cookies.
- `assets/` holds the hero photo in two sizes, the share image and the browser tab icon.
- The page is hidden from search engines for now (`noindex` in `index.html` and `robots.txt`). Remove both when it is ready to launch.
- The serif is Spectral from Google Fonts, the brand style guide's web fallback. The brand typeface is not included because its web licence has not been confirmed for this domain.
